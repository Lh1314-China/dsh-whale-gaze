# 溯光

给 DSH 一双常开的、便宜的眼睛。摄像头或者屏幕上的视频窗口都行。

## 它做什么

- **看**：8fps、64×36 的小帧，本地算运动和肤色，不进模型上下文，0 token。
- **跟**：把画面里动的东西的质心平滑成眼位，驱动皮套眼睛（VTube Studio 的
  `EyeLeftX/Y`、`EyeRightX/Y`）；同时在 `gaze.json` 留一份，别的皮套也能读。
- **记**：每轮思考只多一行「视线：cam 动 34% 偏右中」，20–40 token。
- **定格**：兴趣分过线（默认 55）或模型主动 `freeze`，把当前快照存进 `inbox/`，
  返回路径；要看细节再 `read_image`。原始帧永远不进上下文。

## 怎么用

模型侧只有一个工具：`eye_see`。

- `status` 看源、帧数、最新动静、inbox 和皮套状态
- `start` / `stop` 睁眼闭眼（camera / screen / window）
- `look` 一行场景 + 最新快照路径
- `freeze` 立刻定格一张
- `aim` 手动把眼睛指到某处，`on:false` 放开

## 边界与限制

- 仅 Windows，依赖本机 ffmpeg（dshow / gdigrab）。
- 摄像头是独占设备：停源后 ffmpeg 必须真的退出，否则下次拿不到帧。
- 快照 1fps 覆盖写，定格最多晚一秒。
- v0.1 只做运动/肤色/亮度/场景切换，没有物体识别，也没有前端面板。
- 摄像头默认不自动常开；常开要在配置里写 `autoStart: true`，或者手动 `start` 一次。
- 全程本机，不出网；只有定格过的帧会落盘。
